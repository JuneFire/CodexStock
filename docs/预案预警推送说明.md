# 预案预警推送说明（preplan_alert.py）

## 每天会收到几条消息

| 时间 | 消息 | 内容 |
|---|---|---|
| **09:00** | **L1 红牛看多·定稿** | 红牛预案看多全清单，逐只带 `[强][中][弱][否决]` 档位 + AI 判定 `✅多/·中性/⛔空` + 原文摘要 |
| **09:26 左右** | **竞价排名** | 只给信息不给指令：按竞价涨幅排序，逐只显示 **竞价涨幅 / 竞价金额 / 竞价换手**（+ 板块、AI 判定、档位）；⛔空 的票单独列在下面 |

> 盘中不再推任何消息。红牛中途补发的预案，会在 09:00 那条里自动合并（轮询 5 分钟一次，09:20 后加密到 30 秒）。

## 为什么是 09:00 而不是预案一到就推

- 红牛通常在 07:50–08:00 发图片预案、08:30 左右补文字，**09:00 前内容基本齐了**
- 事件订阅（`im.message.receive_v1`）需要**机器人进群**，而这两个群我们没有机器人权限 → 只能轮询
- 轮询降频到 5 分钟（原 60 秒），一天约 25 次，对飞书接口压力可忽略

如需"预案到一条推一条"，加 `--l1-incremental` 即可（默认关闭）。

## AI 复核做了什么

对当日**所有**红牛看多票逐只跑 DeepSeek（temperature=0，结果按片段哈希缓存）：

| AI 判定 | 显示 | 处理 |
|---|---|---|
| bull | ✅多 | 保留在候选 |
| neutral | ·中性 | 保留在候选（但通常意味着红牛只是提及） |
| bear | ⛔空 | **保留在清单里显示，但不进 09:26 的竞价候选** |

成本：每天约 ¥0.002–0.005；AI 不可用时自动降级（照常推送，只是没有标记）。

## cron（服务器）

```
30 7 * * 1-5 cd /opt/stock_system/CodexStock && PREPLAN_AI=1 \
  /root/venv/bin/python scripts/preplan_alert.py \
  --loop --until 09:35 --l1-final 09:00 --interval 300 >> logs/preplan_alert.log 2>&1
```

## 竞价排名怎么读（09:26 那条）

```
2026-10-28 竞价排名（09:25｜按涨幅排序）

　1. 襄阳轴承(000678) 10cm 竞价 +4.74% ｜ 额 14.92亿 ｜ 换手 20.57% ｜ ·中性 中
　2. 大业股份(603278) 10cm 竞价 -1.51% ｜ 额 18.50亿 ｜ 换手 31.17% ｜ ·中性 中
　3. 冰山冷热(000530) 10cm 竞价 -1.52% ｜ 额 20.56亿 ｜ 换手 39.55% ｜ ✅多 强
　4. 国芳集团(601086) 10cm 竞价 -2.35% ｜ 额 11.97亿 ｜ 换手 14.90% ｜ ·中性 中 🔴L3
　5. 统一股份(600506) 10cm 竞价 -5.04% ｜ 额 7.88亿 ｜ 换手 17.42% ｜ ✅多 强

⛔ AI 判空（红牛原文实为看空/出局）
　· 九阳股份(002242) 竞价 -1.25% ｜ 额 27.93亿 ｜ 换手 16.89%
```

| 字段 | 含义 |
|---|---|
| 竞价涨幅 | 开盘价 / 昨收 − 1（09:25 集合竞价成交价） |
| **竞价金额** | 集合竞价成交额（09:25 时点值，不是全天量） |
| **竞价换手** | 集合竞价换手率 = 竞价成交量 / 流通股本 |
| 板块 | 10cm（主板）/ 20cm（创业板·科创板）/ 30cm（北交所） |
| ✅多 / ·中性 | AI 对红牛原文的判定 |
| 强/中/弱/否决 | 原文里有多明确的买入措辞 |
| 🔴L3 | 同时命中 L3 超跌反核 |

**排序依据可切换**：`--sort gap`（默认，涨幅）｜`--sort amt`（竞价金额）｜`--sort turn`（竞价换手）。

> 消息里**不包含任何买入/仓位指令**——只提供排序信息，买哪只由你决定。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--loop` | — | 轮询模式（cron 用这个） |
| `--until` | 09:35 | 停止时间（要覆盖 09:26 竞价定档） |
| `--l1-final` | 09:00 | L1 定稿推送时间 |
| `--l1-incremental` | 关 | 改为「预案到一条推一条」 |
| `--interval` | 300 | 平时轮询间隔秒（09:20 后自动 30s） |
| `--sort` | gap | 竞价排名排序：gap 涨幅 / amt 金额 / turn 换手 |
| `--once` | — | 跑一次（测试用） |
| `--no-send` | — | 只解析不推送 |
