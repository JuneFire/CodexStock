## 二、四条结论

### 1. 题材强的票，涨停接力确实更好
题材≥2 只：接力 **+7.49%**、复利 **×5.50**、回撤 **8.7%**，比次日收盘卖（+6.49% / ×4.25）更高。
持仓从 1.00 日延长到 1.19 日，回撤没有上升（8.7% → 8.7%）。

### 2. 「只做题材≥2 + 涨停接力」优于「全部 56 笔 + B规则」
| | 交易数 | 复利 | 最大回撤 |
|---|---|---|---|
| 全部 56 笔 · B规则 | 45 | ×5.06 | 27.7% |
| 全部 56 笔 · 涨停接力 | 44 | ×4.10 | 23.0% |
| **题材≥2 · 涨停接力** | **21** | **×5.50** | **8.7%** |

收益更高、回撤只有 1/3、交易数减半。

### 3. 题材强的票，**不要**高开就卖竞价（反直觉）
题材≥2 组里「分档卖竞价」是**负贡献** −0.52%/笔：
- 海陆重工（高开 +9.0% 卖竞价）+13.58 vs 接力 +7.74 → 赚 +5.84
- 神剑股份（高开 +10.0% 卖竞价）+25.08 vs 接力 +36.26 → **亏 −11.18**
- 辽宁能源（高开 +10.0% 卖竞价）+10.85 vs 接力 +18.99 → **亏 −8.14**
净 −13.48 / 26 笔 = −0.52%/笔。

原因：题材强时「高开 10% 一字板继续封」是常态，卖在竞价等于把后面的板让掉。
题材≥4 只时更极端——分档与次日收盘完全相同（高开的那几笔都是一字板，开=收）。

### 4. 题材弱的孤票，只能靠分档救，但救不回来
题材<2 组所有规则复利都 ≤1.02、回撤 42.9%~55.2%。分档卖竞价能把它从 +0.43% 提到 +1.59%（×0.60 → ×0.84），B规则勉强 ×1.02，但回撤 42.9%。
**正确做法是不做，不是换卖出规则。**

## 三、稳健性：接力增益 100% 来自 3 笔

题材≥2 组 26 笔里，接力与次日收盘卖**只有 3 笔有差异**：

| 日期 | 名称 | 题材 | 持有 | 次日收盘 | 涨停接力 | 差 |
|---|---|---|---|---|---|---|
| 2025-12-24 | 神剑股份 | 商业航天 | 4 日 | +25.08% | +36.26% | +11.18 |
| 2026-01-06 | 雷科防务 | 商业航天 | 2 日 | +15.24% | +22.00% | +6.76 |
| 2026-03-24 | 辽宁能源 | 电力 | 2 日 | +10.85% | +18.99% | +8.14 |

**剔除这 3 笔后（剩 23 笔）：次日收盘 +5.11% / ×2.98，涨停接力 +5.11% / ×2.98 —— 完全相同。**
即 26 笔里只有 3 笔（11.5%）真的接得动（D+1 继续封板）。
题材料的作用不是让接力更容易成功，而是让**买入后的基准收益**更高（+0.43% → +6.49%）。

另外：全部 56 笔里接力增益最大的单笔（豫能控股 +19.15%、持股 3 日）在题材<2 组，说明题材家数无法完全解释接力成功。

## 四、可实盘化的口径：用 T-1 题材家数

「题材当日涨停家数」要 D 日收盘后才知道，09:25 做决策时只能用 **T-1 家数**（`themeN1`）。

| 筛子 | n | 次日收盘卖 | 涨停接力 | B规则 |
|---|---|---|---|---|
| **T-1 题材家数 ≥1** | 31 | +5.90% / ×5.26 / dd10% | **+6.64% / ×6.65 / dd10%** | +6.46% / ×6.44 / dd10% |
| T-1 题材家数 ≥2 | 25 | +6.45% / ×3.94 / dd11% | +7.17% / ×4.75 / dd11% | +6.95% / ×4.60 / dd11% |
| T-1 题材家数 ≥3 | 20 | +5.91% / ×2.69 / dd6% | +6.81% / ×3.24 / dd6% | +6.54% / ×3.14 / dd6% |
| T-1 题材家数 ≥5 | 16 | +6.64% / ×2.39 / dd6% | +7.76% / ×2.89 / dd6% | +7.43% / ×2.79 / dd6% |
| **T-1 题材家数 <2** | 31 | +0.66% / ×0.88 / dd31% | +1.60% / ×1.07 / dd32% | +2.46% / ×1.50 / dd31% |

**T-1 题材家数 ≥1 是最佳实盘筛子**：31 笔、接力 ×6.65、回撤 10%（对比全部 56 笔接力 ×4.10 / dd23%）。
含义：这只票的题材昨天至少已经有 1 只涨停 → 不是「凭空冒出来的孤票」。这个条件 09:25 完全可见（读前一交易日涨停池的 `limitUpReason` 按题材聚合）。

其他可用筛子（均为 T-1 可见）：
- 涨停原因主词家数 `reasonN >= 3`（n=7）：接力 **+12.80%** / ×2.10 / dd0%
- `reasonN == 1`（n=12，孤票）：接力 +4.74% / ×1.63 / dd12%
- T-1 家数 ≥2 且 T-1→D 扩散 `delta > 0`（n=10）：接力 +10.15% / ×2.50 / dd2%

## 五、落地建议

1. **买入前加题材筛**：`T-1 题材涨停家数 ≥ 1`（否则不登记买入）。对应到生产：`backend/hithink_feed.py` 的 `sanyi_eligible` / `isSanyi` 之外再加一个 `themeWarm` 标记，数据取自前一交易日涨停池按 `limitUpReason` 聚合。
2. **卖出规则按题材分组**：
   - 题材温（T-1 ≥1）→ **纯涨停接力**（D+1 起收盘封板才续持，断板当日收盘卖），**不做分档卖竞价**
   - 题材冷（T-1 = 0）→ 不买
3. **不要用「高开≥6% 卖竞价」这个分档**：对题材票是负贡献（−0.52%/笔），只在孤票上有正贡献，而孤票本身不该做。
4. 待验证：把 `themeWarm` 加进页面，看 2026-11 之后的实盘命中与滑点。
