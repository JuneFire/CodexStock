# 用「线上新口径」重跑回测：AI 扩围对成绩的影响

生成：2026-10-28　触发原因：今天把线上解析改成「AI 判定所有被点名的票」+「OCR 空格清洗」
脚本：`scripts/build_signals_v3.py`（重建历史信号）、`scripts/combo_l1_l3.py`（回测）

## 一、为什么必须重跑

之前的回测信号全部来自 `plans_fixed.jsonl`——**词表法 + ±60 字窗口**，会系统性漏票（今天实测：红牛点名 5 只，词表只认出 3 只，冰山冷热直接消失）。

今天线上改成 AI 判定「所有被点名的票」，如果不把这条用到历史数据上，回测就是拿旧口径的成绩去指导新口径的实盘。

## 二、三套信号口径

|---|---|---|

## 四、结论：解析更全 ≠ 选股更好

**v3（AI 扩围）把 L1 从 +479.8% 打到 +64.0%。** 原因是机制性的：

```
L1 的选股规则是「候选里竞价涨幅最高的一只」
候选从 138 个 → 251 个（AI 补进了大量「红牛只是提了一句」的票）
→ 同一天里，涨幅最高的那只经常从「高置信票」变成「噪音票」
→ 选股质量下降
```

**v1 的"漏票"实际上起到了高置信过滤的作用**：词表只认"买点/低吸/打底"这类硬词，天然筛掉了只是被提及的票。

**v3x（双确认）介于两者之间**（+231.8%）：AI 认可 + 词表认可，说明两只"筛子"叠加有意义，但仍不如单用词表。

## 五、这对线上意味着什么

| 用途 | 应该用哪个 |
|---|---|
| **线上推送**（给你看信息） | ✅ **v3 口径**（AI 扩围），因为你要看到红牛说过的每一只票，包括判空的 |
| **回测/预期收益** | ✅ **v1 口径**（保守），+479.8% / 合并 +905.8% 仍是最可靠的数字 |
| 别做的事 | ❌ 拿 v3 的候选池去套"竞价最高"机械选股 |

也就是说：**线上"多看"和回测"少选"要分开**。推送负责完整，选股规则负责收敛。

## 六、下一步建议

如果想让 v3 候选池也能有 v1 的水平，选股规则需要重新设计。可扫的方向：

1. **只买 AI bull 且竞价落在 -3%~+10%**（今天测过区间选股有效）
2. **AI bull 且原文含「买点/低吸/打底」**（= 把 v3 的完整性和 v1 的硬词叠加）
3. **AI bull 且 Tier=强**
4. 用 AI 输出的置信度/理由长度做加权

要跑哪几个我可以直接扫，但要注意：**这已经是在同一段行情上第 N 次调参**，任何"收益翻倍"的结论都必须先过分半检验。
