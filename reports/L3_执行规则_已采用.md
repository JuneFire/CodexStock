# L3 执行规则（已采用，2026-10-27 定稿）

## 规则

信号日 D（盘前确认 L3：红牛看多 × 来去空头风标 × 红牛原文含反核词）

```
D 日开盘    全仓买入（不留现金）
盘中        跌破买入价 -5% → 立即清仓止损（T+1 之后才可执行）
D+1 收盘    收绿（收盘 < 前一日收盘）→ 清仓
            收红 → 尾盘卖出 1/3
D+2~D+4     每日新高（当日最高 > 入场以来最高）才继续持有；不新高当日收盘清仓
D+3 收盘    再卖出剩余仓位的 1/2
D+5 收盘    剩余全部清仓
```

## 与其他口径对比

| 规则 | 收益 | 回撤 |
|---|---|---|
| **本规则（-5% 止损 + 分批止盈）** | **+378.6%** | **-14.3%** |
| 同规则但不带止损 | +271.4% | -19.2% |
| 收红卖 1/2 + 剩余现金开新仓 | +174.6% | -23.6% |
| 分批止盈（3 天新高才清，无 D+1 收绿规则） | +155.9% | -34.2% |
| 最简：D 买 → D+1 收盘全卖 | +179.1% | -19.2% |
| 最简 + 5% 止损 | +235.8% | -14.3% |

## 关键点

1. **-5% 止损是这套规则的核心**：它把「D+1 低开阴跌到收盘才砍」的情况（金螳螂 4-24，-19.2%）截断在 -5%，直接带来 +107 个百分点的收益增量、回撤从 -19.2% 降到 -14.3%。
2. **「D+1 收绿就清」与「-5% 止损」互补**：止损管盘中急跌，收绿管尾盘走弱。
3. **不要用卖出后的现金开新仓**：会把大赢家仓位砍半、买到后期低质量信号，实测收益从 +271% 掉到 +175%。
4. **未计手续费**：23 笔 × 平均约 2 次卖出 ≈ 0.15%/笔 ≈ -3,500 元，实际约 4.4 万（+340%）。

## 复现

```bash
NO_NET=1 python scripts/l3_exit_sim.py                       # 默认即本规则
NO_NET=1 python scripts/l3_exit_sim.py --detail              # 逐笔卖出明细
NO_NET=1 python scripts/l3_exit_sim.py --no-stop             # 关掉止损对照
NO_NET=1 python scripts/l3_exit_sim.py --first-sell 0.5      # 收红卖一半
NO_NET=1 python scripts/l3_exit_sim.py --fixed 10000         # 每笔固定 1 万
```

## 局限

- 样本仅 23 笔 / 7 个月；10 月后无新样本
- 止损价假设能成交：一字跌停或跳空低开时可能滑到 -8~-10%
- 分批卖出滑点高于一次性卖出
- 「新高」判定用当日最高价 vs 入场以来最高，未考虑盘中假突破
