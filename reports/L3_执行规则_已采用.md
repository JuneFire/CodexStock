# L3 执行规则（已采用，2026-10-30 更新）

> 旧的"收绿清仓 / 尾盘卖 1/3 / D+2~D+4 新高才续持 / D+5 清仓"版本已废止（`reports/L3逐笔核对报告.md` 解释过为何改为两段式）。
> 2026-10-30 起出场改为「D+1 涨停续持到断板」。

## 规则

信号日 D（盘前 L3：红牛看多 ∩ 来去空头风标/看空 ∩ 红牛原文含反核词）

```
D 日开盘    全仓买入（满仓单票）
D 日        不能卖（T+1）

D+1 起     盘中跌破买入价 -5% → 清仓止损
           （跳空低开时按开盘价成交，不是按 -5% 成交）

D+1 尾盘   仍然涨停 → 不卖，一直持有，每天尾盘看是否还封着
           直到某天收盘不再涨停（断板）→ 当晚按收盘价卖

D+1 未涨停 → 收盘卖半仓
D+2       剩余半仓收盘卖（若盘中跌破 -5% 则止损价卖）
```

多只候选时买**竞价涨幅最高**、且非涨停开盘（能买到）的那只。

## 已知偏差

止损按 -5% 精确成交偏乐观。23 笔里有 3 笔 D+1 跳空开盘就低于 -5%，实际只能按开盘价卖：04-24 金螳螂（5.05→4.39，-17.5%）、07-30 立新能源（11.26→11.12）、10-08 襄阳轴承（12.35→12.00）。按 `min(止损价, 开盘价)` 修正后 L3 从 +308.7% 降到 +234.8%，合并从 +1010.6% 降到 +825.9%。用 `--gap-fill` 复现。
