# L1 + L3 合并策略回测：有 L3 就梭哈 L3，否则梭哈 L1

生成：2026-10-27　脚本：`scripts/combo_l1_l3.py`
资金 1 万、满仓单票、复利；费用 0.1%/笔（佣金+印花）

## 一、规则

```
每日按优先级：
  ① 当日有 L3 信号（红牛看多 ∩ 来去看空/空头风标 ∩ 红牛原文含反核/低吸/次弱）
     → 梭哈 L3 中竞价涨幅最高、且非涨停开盘的那只
  ② 否则 → 梭哈 L1（红牛看多−看空）中竞价涨幅最高、非涨停开盘的那只

出场（按信号源不同）：
  L3：D+1 收盘卖半仓 + 剩余半仓 D+2 收盘卖；盘中跌破成本 -5% 立即止损
  L1：D+1 收盘全出（隔日卖）

资金占用：卖完才算空仓（L3 半仓留到 D+2 → 下次买入最早 D+3）
```

## 六、两个参数验证

**1）L3 必须持 2 天，不能隔日就跑**

| L3 出场口径 | 合并策略 | 纯 L3 |
|---|---|---|
| **定稿：半仓 D+1 + 半仓 D+2** | **+905.8%（52 笔，回撤 -15.6%）** | +266.6%（23 笔） |
| 统一 D+1 收盘全出 | +464.4%（56 笔，回撤 -19.7%） | +234.7%（25 笔） |

L3 的收益一半来自 D+2 那半仓 → **绝对不要 D+1 全清**。

**2）L3 止损 3%~8% 差别不大，10% 明显变差**

| 止损 | 期末 | 收益 | 胜率 | 回撤 |
|---|---|---|---|---|
| 3% | 113,974 | +1039.7% | 67.3% | -15.6% |
| **5%（定稿）** | 100,581 | +905.8% | 67.3% | -15.6% |
| 8% | 107,450 | +974.5% | **71.2%** | -15.6% |
| 10% | 84,487 | +744.9% | 69.2% | -19.5% |

因为止损只触发少数几次，3%~8% 区间内差异属噪声；**保持 5% 定稿即可**（不要放宽到 10%）。

## 七、为什么合并会更好（机制解释，不是拟合）

1. **L3 是独立信源**：它来自"红牛和来去对同一只票方向相反"的**冲突**，和 L1 的"一致看多"不重叠，所以能互补而不是重复。
2. **L3 天然低频（23 笔 vs 56 笔）**：只在冲突日才出现，正好补在 L1 选不出好票的日子。
3. **L3 回撤小（-10.1%）**：超跌反核的买点本来就低，亏损空间小 → 给组合降波动。
4. **L3 优先级解决了"同一天两套信号打架"**：不用纠结买哪个，L3 来了就做 L3。

## 八、诚实提示（风险）

1. **52 笔样本仍然偏小**：单笔差异 t=0.64 不显著，"收益翻倍"里有运气成分。
2. **L3 的信号依赖"红牛看多 ∩ 来去看空"**，若某天来去不发空头风标，L3 就不出现 → 策略退化为 L1。
3. **L3 的 -5% 止损需要盘中监控**：D+1 开盘后要盯盘，跌破成本 -5% 立刻卖；不盯盘就变成"半仓 D+1 + 半仓 D+2"的无止损版。
4. **实盘执行**：09:00 推送里如果出现 🔴L3，说明今天是 L3 日；09:26 竞价排名里 L3 那只就是标的，按竞价最高选。
