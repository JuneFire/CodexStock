# L1 + L3 合并策略回测：有 L3 就梭哈 L3，否则梭哈 L1

生成：2026-10-27　最近更新：2026-10-30（L3 出场改为「D+1 涨停续持到断板」）
脚本：`scripts/combo_l1_l3.py`
资金 1 万、满仓单票、复利；费用 0.1%/笔（佣金+印花）

## 一、规则

```
每日按优先级：
  ① 当日有 L3 信号（红牛看多 ∩ 来去看空/空头风标 ∩ 红牛原文含反核/低吸/次弱）
     → 梭哈 L3 中竞价涨幅最高、且非涨停开盘的那只
  ② 否则 → 梭哈 L1（红牛看多−看空）中竞价涨幅最高、非涨停开盘的那只

出场（按信号源不同）：
  L3：跌破成本 -5% 止损（D+1 起才可卖，T+1 合规）
      D+1 尾盘涨停 → 不卖，一直持有到断板日收盘卖
      D+1 未涨停   → 收盘卖半仓 + 剩余半仓 D+2 收盘卖
  L1：D+1 收盘全出（隔日卖）

资金占用：卖完才算空仓（L3 续持或留半仓到 D+2 → 下次买入顺延）
```

口径变更（2026-10-30，用户提出）：
1. **止损只能在 D+1 及以后触发**（A 股 T+1，当日不能卖）。代码一直是这么写的（`i=买入日`、`j=i+1`，所有卖出判断只读 D+1 及以后的 bar），本次只把文案从"盘中跌破立即止损"改成"**D+1 起**"。
2. **D+1 尾盘继续涨停就一直拿着，直到断板那天收盘卖**（原规则是无条件 D+1 卖半仓 + D+2 卖剩余）。

## 七、为什么合并会更好（机制解释，不是拟合）

1. **L3 是独立信源**：它来自"红牛和来去对同一只票方向相反"的**冲突**，和 L1 的"一致看多"不重叠，所以能互补而不是重复。
2. **L3 天然低频（23 笔 vs 56 笔）**：只在冲突日才出现，正好补在 L1 选不出好票的日子。
3. **L3 回撤小（-10.1%）**：超跌反核的买点本来就低，亏损空间小 → 给组合降波动。
4. **L3 优先级解决了"同一天两套信号打架"**：不用纠结买哪个，L3 来了就做 L3。

## 八、诚实提示（风险）

1. **50 笔样本仍然偏小**：单笔差异 t≈0.9 不显著，"收益翻倍"里有运气成分。
2. **续持规则只有 6 笔受益/受损**（03-23 华电辽能 +13.8pp、05-11 大唐发电 +2.8pp、05-28 香江控股 +2.6pp、07-20 哈药 +1.5pp；反例 05-06 金螳螂 -2.8pp、08-31 金健米业 -3.6pp），+105pp 的净提升几乎全靠华电辽能一笔 → 比“半仓 D+1+D+2”更依赖运气，但它符合“涨停不卖”的交易直觉。
3. **止损成交价按 -5% 精确成交偏乐观**：L3 23 笔中有 3 笔 D+1 **跳空开盘就低于 -5%**，实际只能按开盘价成交——04-24 金螳螂（止损价 5.05 / 开 4.39 = -17.5%）、07-30 立新能源（11.26 / 11.12）、10-08 襄阳轴承（12.35 / 12.00）。按 `成交价 = min(止损价, 开盘价)` 修正后：纯 L3 **+308.7%→+234.8%**、合并 **+1010.6%→+825.9%**，回撤 -15.6%→-17.6%，胜率不变。**该修正尚未设为默认口径**，用 `--gap-fill` 可复现。
4. **L3 的信号依赖"红牛看多 ∩ 来去看空"**，若某天来去不发空头风标，L3 就不出现 → 策略退化为 L1。
5. **L3 的 -5% 止损 + 续持需要每天盯盘**：D+1 起跌破成本 -5% 要卖；尾盘要确认是否还封涨停。
6. **实盘执行**：09:00 推送里如果出现 🔴L3，说明今天是 L3 日；09:26 竞价排名里 L3 那只就是标的，按竞价最高选。
